# Drive

C1/C2 考题祥记。

- [高速](0.md)
- [证](1.md)

- 开4个小时车、最少休20分钟
- 右让左、左让直、转弯让直行、行人等
- 致人重伤、死亡、公私财产损失等
    - 未逃逸：3年以下
    - 逃逸：3年以上~7年以下
    - 逃逸后导致未即使救治死亡：7年以上
- 进入高速：打左转向灯；驶出高速：打右转向灯
- 黄色尺子：注意积水
- 交警扣车不扣人
- 国道G-红底、省道S-黄底、县道X-白底、乡道Y-白底
- 车上该有的证、标、牌有问题 → 可以扣车。/ 2证（行驶证、驾驶证）、2标（检验合格标志、保险标志）、1号牌（机动车号牌）

- 机动车驾驶人参加满分教育现场学习不得少于**2天**、网络学习不得少于**5天**、小车学7天/最多60天，大车30天/最多120天
- 一个周期累计12分 -> 法律法规相关知识（科一）、累计24分 -> 法律法规（科一） + 道路（科三）、累计36分 -> 法律法规 + 场地（科二）+ 道路（科三）
- 复杂路段**50米**不得停车、加油站、消防等**30米**不得停车
- 无中心线：城市道路限速30，公路限速40；有中心线：城市道路限速50，公路限速70
- 只要是危险路口、环境、牵引挂车工作时：限速30，
- 红色禁令、黄色警告/警示、蓝色指示/指路、棕色景点、绿色地距、黑色解除/辅助
- 两条692、一条158
- 转移抵押变更报废要登记
- 虚假材料500块以下 + 1年内不得考试；审验教育弄虚作假1000块；考试贿赂2000块
- 公益1小时1分、现场1小时2分
- 换找居住地、车找登记地、人找核发地
- 防碰撞=FCW、定速巡航系统=CCS、自适应巡航=ACC、电子制动力分配=EBD、交通标准识别=TSR、车辆紧急制动=EBA、车辆盲点=BSA、车辆盲点监控=BSD
- 车辆牵引力控制=TCS/ASR/TRC、自动变道=ALC、自动刹车辅助=AEB、电子稳定控制=ESP
- 实时交通=TMC、随动转向前照灯=AFS
- 年检：非运营10年，运营5年；申请检测标志：10年=2年申请一次，10年以下=1年申请一次
