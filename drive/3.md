# 分

## 1分
- 擅自改装 = 1分
- 机动车行驶超过规定限宽、限高、长度 = 1分
- 不按规定会车、非高速/城市快速路倒车、掉头 = 1分
- 不按规定使用车内灯光 = 1分
- 不系安全带 = 1分
- 不戴头盔 = 1分
- 7座以下未进行安全技术检验 = 1分
- 高速/城市快速路以外的道路 倒车 = 1分
- 校车在 高速/城市快速路以外的道路 时速未超过20% = 1分
- 违法警令标志、标线 = 1分

## 3分
- 高速/城市快速路以外的道路 不按规定车道行驶/逆行 = 3分
- 高速公路 低于规定最低时速 = 3分
- 不按规定按照机动车车牌 = 3分
- 7座以下载客未超过50% = 3分
- 7座以上物品运输超过4小时未休息 + 休息时间少于20分 = 3分
- 货车载物未超过50% = 3分
- 未规避校车 = 3分
- 未避让行人、减少、停车 = 3分
- 车辆发生故障未使用正确灯光 + 警告标志 = 3分


## 6分
- 驾驶证暂扣、扣留期间驾驶机动车 = 6 分
- 轻微伤/财产损失 + 逃逸 + 不构成犯罪 = 6分
- 高速/城市快速路 违法占用应急车道 = 6分
- 客运、校车载人超过20%以下 = 6分
- 7座以上载客未超过50% = 6分
- 7座以下载客超过50% = 6分
- 7座以下高速/城市快速路 超速20%~50% = 6分
- 货车载物超过50% = 6分
- 高速/城市快速路 超速20%~50% = 6分
- 借道超车、占用车道 = 6分
- 未悬挂警示标志 = 6分

## 9分
- 准驾不符合 = 9分、200~1000
- 7座以上载客超过50% = 9分
- 7座以上载客、危险物品运输超过4小时未休息 + 休息时间少于20分 = 9分
- 遮挡号码牌、未悬挂 = 9分
- 未取得校车驾驶资格证驾驶校车的 = 9分
- 7座以上校车、危险运输、客车、货车在高速、城市快速路超速50%以上的 = 9分
- 机动车高速、城市快速路违法停车 = 9分

## 12分
- 代替他人接受处罚 = 12分、3倍罚款、最高5w
- 客运、校车载人超过20%以上 = 12分
- 非客运、校车高速超速50% = 12分
- 高速/城市快速路逆行、倒车 = 12分
- 酒驾 = 12分、暂扣6个月、1000~2000
