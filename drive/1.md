# 证

## 申领

| 准驾车型                |       申请年龄 |
| ----------------------- | -------------: |
| **C1 / C2 小型汽车**    | **18周岁以上** |
| **C6 轻型牵引挂车**     |     **20～70** |
| **A3 / B1 / B2 中大型** |     **20～63** |
| **A1 / A2 大客/重牵**   |     **22～63** |

## 人和车的证件

- 人：驾驶证 → 证明“人能开什么车”
- 车：行驶证 → 车的身份证
- 车：登记证书 → 车的户口本
- 车：号牌 → 车的号码

## 去哪办

- 车 → 重点记登记地车管所
- 人 → 驾驶证业务很多可异地办理

## 高频数字

- 驾驶证到期 → 提前90日换证
- 补换正式号牌 → 可申领≤15日临牌

## 丢失

- 驾驶证丢 → 可补证
- 登记证书 / 行驶证 / 号牌丢 → 登记地补换
- 补新以后 → 旧的作废

## 一个超级好用的判断

- 驾驶证 = 人
- 登记证书 + 行驶证 + 号牌 = 车

## 处罚

如果是驾驶已经达到报废标准的机动车上道路行驶：

- 车：收缴 + 强制报废
- 人：罚款 200～2000 元 + 吊销驾驶证

|     年限 | 典型情形                                       | 怎么理解             |
| -------: | ---------------------------------------------- | -------------------- |
|  **1年** | 隐瞒情况、提供**虚假材料**申领驾驶证           | **还没骗到证** → 1年 |
|  **2年** | **吊销驾驶证**后的一般情形                     | 一般吊销 → 2年       |
|  **3年** | 欺骗、贿赂等手段**已经取得驾驶证**，被撤销     | **已经骗到证** → 3年 |
|  **5年** | **醉酒驾驶机动车**、危险驾驶被吊销             | 醉驾 → 5年           |
| **终身** | 造成重大交通事故后**逃逸并构成犯罪**等法定情形 | 终身不得重新取得     |
