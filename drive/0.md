## 高速

限速 60～120；二左100，三左110中90；跟车百百、百下五十；雾天261、145、520；故障牌150；错出口继续走。

## 1、高速车道限速

| 同方向车道数  | 左侧最低速度 | 中间车道最低速度 | 最右侧最低速度 |
| ------------- | -----------: | ---------------: | -------------: |
| **2车道**     | **100 km/h** |                — |    **60 km/h** |
| **3条及以上** | **110 km/h** |      **90 km/h** |    **60 km/h** |

高速公路总体：最高 120，最低 60。这是《道路交通安全法实施条例》第七十八条的规定；如果道路上的限速标志另有规定，则按标志走。

## 2、高速车距

| 高速行驶速度   | 与前车安全距离 |
| -------------- | -------------: |
| **> 100 km/h** |   **≥ 100 米** |
| **< 100 km/h** |    **≥ 50 米** |

高速车距：过百留百米，百下留五十。

## 3、高速能见度（雾天）

|       能见度 |      最高车速 |         最小车距 |
| -----------: | ------------: | ---------------: |
| **< 200 米** | **≤ 60 km/h** |     **≥ 100 米** |
| **< 100 米** | **≤ 40 km/h** |      **≥ 50 米** |
|  **< 50 米** | **≤ 20 km/h** | **尽快驶离高速** |

261 → 200 米、60 码、100 米
145 → 100 米、40 码、50 米
520 → 50 米、20 码、尽快驶离

## 4、高速发生故障

**开双闪** → **能移就移** → **150米外放警告牌** → **人撤到安全位置** → **报警**

## 5、错过出口

错过就继续走，下一个出口再出去。

## 6、进入 / 驶离高速

进入高速：**加速车道提速** → **观察** → **不妨碍主路车辆** → **汇入**。
驶离高速：**提前进入减速车道** → **再减速驶出**。

## 7、禁止行为

倒车、逆行、掉头、随意停车、骑轧车道分界线、非紧急情况占用应急车道。
