# 英语十大词性

| 词性                | 英文         | 核心作用               | 常见问题           |
| ------------------- | ------------ | ---------------------- | ------------------ |
| [名词](./1/8.md)    | Noun         | 人、事物、地点、概念   | 谁？什么？         |
| [代词](./1/9.md)    | Pronoun      | 替代名词               | 他/它/这/那些      |
| [动词](./1/10.md)   | Verb         | 表示动作/状态          | 做什么？           |
| [形容词](./1/11.md) | Adjective    | 描述名词的特征         | 什么样的？         |
| [副词](./1/12.md)   | Adverb       | 修饰动词/形容词/句子等 | 怎么样？           |
| [介词]./1/6.md    | Preposition  | 表示关系               | 在哪、朝哪、为了谁 |
| [冠词]./1/7.md    | Article      | 限定名词               | a/an/the           |
| [连词](./1/14.md)   | Conjunction  | 连接语言单位           | and/but/because    |
| [感叹词](./1/15.md) | Interjection | 表达情绪和反应         | wow/oh             |
| [数词](./1/13.md)   | Numeral      | 表示数量               | one/two/first      |

<!-- 名词负责描述事物，动词负责描述动作，形容词负责描述特征，副词负责修饰，而连词负责建立连接。 -->
