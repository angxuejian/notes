# 连词（Conjunction）

连接词与词、短语与短语、句子与句子的词

## 1、常见连词

| 连词        | 含义       | 例句                                 |
| ----------- | ---------- | ------------------------------------ |
| and         | 和、并且   | Tom and Jack are friends.            |
| but         | 但是       | I like coffee, but I don't like tea. |
| or          | 或者       | Do you want coffee or tea?           |
| because     | 因为       | I stayed home because it rained.     |
| so          | 所以       | It rained, so I stayed home.         |
| although    | 虽然       | Although it rained, I went out.      |
| if          | 如果       | If it rains, I will stay home.       |
| unless      | 除非       | You can go unless it rains           |
| both...and  | 两者都     | Both Tom and Jack are happy.         |
| either...or | 要么……要么 | Either tea or coffee is fine         |
| than        | 比         | He is taller than I am.              |
| as...as     | 和……一样   | She is as beautiful as her sister.   |

- A + be + as + 形容词原级 + as + B = She is as beautiful as her sister.
