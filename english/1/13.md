# 数词（Numeral）

基数词和序数词

## 1、基数词

### 1.1、1~100

| 数字 英语 | 数字 英语    |
| --------- | ------------ |
| 1 one     | 11 eleven    |
| 2 two     | 12 twelve    |
| 3 three   | 13 thirteen  |
| 4 four    | 14 fourteen  |
| 5 five    | 15 fifteen   |
| 6 six     | 16 sixteen   |
| 7 seven   | 17 seventeen |
| 8 eight   | 18 eighteen  |
| 9 nine    | 19 nineteen  |
| 10 ten    | 20 twenty    |

- 1～10：基础数字。
- 11、12：特殊词，单独记。
- 13～19：大部分以 -teen 结尾。

| 数字 | 英语    |
| ---- | ------- |
| 20   | twenty  |
| 30   | thirty  |
| 40   | forty   |
| 50   | fifty   |
| 60   | sixty   |
| 70   | seventy |
| 80   | eighty  |
| 90   | ninety  |

十位数 + 个位数 = Twenty + one = Twenty-one

- Sixty-three = 63
- ninety-nine = 99

### 1.3、年份

年份按照两位数一组来读。

| 年份 | 英语读法                                                 |
| ---- | -------------------------------------------------------- |
| 1998 | nineteen ninety-eight                                    |
| 2024 | twenty twenty-four                                       |
| 2026 | twenty twenty-six                                        |
| 1985 | nineteen eighty-five                                     |
| 2000 | two thousand                                             |
| 2005 | two thousand and five（英式）/ two thousand five（美式） |
| 2010 | twenty ten                                               |
| 2015 | twenty fifteen                                           |

记忆规律：

- 1900 年代：通常拆成 19 + 后两位。
- 2000 年：two thousand。
- 2001–2009 年：通常读 two thousand and ...（英式）。
- 2010 年以后：通常可以拆成 20 + 后两位。

### 1.4、时间

| 时间  | 英语读法              |
| ----- | --------------------- |
| 8:00  | eight o'clock         |
| 9:03  | nine oh three         |
| 9:15  | nine fifteen          |
| 10:30 | ten thirty            |
| 12:50 | twelve fifty          |
| 15:45 | three forty-five p.m. |

- o'clock 表示整点
- 0 读作 oh = 03 = oh three

## 2、序数词

除了 1-first、2-second、3-third 之外，其余都是`原单词 + th`

| 日期 | 英文读法     |
| ---- | ------------ |
| 1号  | first        |
| 2号  | second       |
| 3号  | third        |
| 4号  | fourth       |
| 5号  | fifth        |
| 10号 | tenth        |
| 15号 | fifteenth    |
| 20号 | twentieth    |
| 21号 | twenty-first |
| 26号 | twenty-sixth |

| 月份 | 英文      | 常用缩写 |
| ---- | --------- | -------- |
| 1月  | January   | Jan.     |
| 2月  | February  | Feb.     |
| 3月  | March     | Mar.     |
| 4月  | April     | Apr.     |
| 5月  | May       | May      |
| 6月  | June      | Jun.     |
| 7月  | July      | Jul.     |
| 8月  | August    | Aug.     |
| 9月  | September | Sep.     |
| 10月 | October   | Oct.     |
| 11月 | November  | Nov.     |
| 12月 | December  | Dec.     |

| 中文   | 英文      | 缩写 |
| ------ | --------- | ---- |
| 星期一 | Monday    | Mon. |
| 星期二 | Tuesday   | Tue. |
| 星期三 | Wednesday | Wed. |
| 星期四 | Thursday  | Thu. |
| 星期五 | Friday    | Fri. |
| 星期六 | Saturday  | Sat. |

- 2026年11月20日 = November 20, 2026 = November twentieth, twenty twenty-six
- 2024年5月10日 = May 10, 2024 = May tenth, twenty twenty-four
- 2026年11月23日，星期一 = Monday, November 23, 2026 = Monday, November twenty-three, twenty twenty-six
