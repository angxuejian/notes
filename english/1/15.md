# 感叹词（Interjection）

用来表达人的情绪、感受、反应或语气的词。

## 1、常见感叹词

| 感叹词 | 中文含义     | 表达的情绪     |
| ------ | ------------ | -------------- |
| Oh!    | 哦！         | 惊讶、恍然大悟 |
| Wow!   | 哇！         | 惊叹、赞美     |
| Hey!   | 嘿！喂！     | 引起注意       |
| Ah!    | 啊！         | 明白、惊讶     |
| Oops!  | 哎呀！       | 出错、失误     |
| Hmm    | 嗯           | 思考、犹豫     |
| Well   | 嗯……那么     | 犹豫、引出话题 |
| Yuck!  | 呸！真恶心！ | 厌恶           |
| Yay!   | 耶！         | 开心、兴奋     |
| Alas!  | 唉！         | 遗憾、悲伤     |

以下是带含义的感叹词：
- damn
- oh my god
- jesus christ
- shut up
- goddamn it
- what the fuck
- alright
