# 代词（Pronoun）

## 1、人称代词

指代各种人称

| 人称     | 单数             | 复数   |
| -------- | ---------------- | ------ |
| 第一人称 | I                | we     |
| 第二人称 | you              | you    |
| 第三人称 | he / she / it    | they   |

人称代词有`主格`、`宾格`之分，以上都是主格。

| 人称          | 主格       | 宾格        |
| ------------- | ---------- | ----------- |
| 第一人称单数  | I          | me          |
| 第二人称单数  | you        | you         |
| 第三人称单数  | he/she/it  | him/her/it  |
| -             | -          | -           |
| 第一人称复数  | we         | us          |
| 第二人称复数  | you        | you         |
| 第三人称复数  | they       | them        |

## 2、物主代词

指代某个人称的`所属关系`，表示`谁的`，`物主`你可以直接理解成：**拥有某个东西的人**，所以物主代词解决的问题就是：**这个东西是谁的？**，比如：**This is `my` phone.**，这里 my = 我的，表示 phone 属于我。

### 名词前使用

| 人称     | 单数         | 复数   |
| -------- | ------------ | ------ |
| 第一人称 | my           | our    |
| 第二人称 | your         | your   |
| 第三人称 | his/her/its  | their  |

示例：

- my phone
- our team
- their project

### 可以独立使用

| 人称     | 单数          | 复数    |
| -------- | ------------- | ------- |
| 第一人称 | mine          | ours    |
| 第二人称 | yours         | yours   |
| 第三人称 | his/hers/its  | theirs  |

示例：

- The phone is mine
- The team is ours
- The project is theirs

## 3、反身代词

反身代词 = `自己`，动作的执行者和承受者是同一个人。比如：**I hurt myself.**

> 单数 = self，复数 = selves

| 人称     | 单数                   | 复数        |
| -------- | ---------------------- | ----------- |
| 第一人称 | myself                 | ourselves   |
| 第二人称 | yourself               | yourselves  |
| 第三人称 | himself/herself/itself | themselves  |

示例：

- I like myself.
- You hurt yourselves
- he did it himself

---

> 代词体系：
>
> I → me → my → mine → myself
>
> 我 → 我 → 我的 → 我的东西 → 我自己

## 4、指示代词

### 指代人、事物或概念

| 指   | 单数 | 复数   |
| ---- | ---- | ------ |
| 近指 | this | these  |
| 远指 | that | those  |

示例：

- This car is good. -> 这辆车很好。
- That tree is bad. -> 那棵树不好。
- These teams are good. -> 这些队伍都不错。
- Those foods are so bad. -> 那些食物种类都很糟糕。

### 其他具有指代功能的词（指代上文内容）

> this / that 才是真正典型的**指示代词**。

| 词       | 核心意思       | 指代什么                   |
| -------- | -------------- | -------------------------- |
| **such** | 这样的、这种   | 前面的**类型/性质/情况**   |
| **same** | 相同的、同样的 | 和前面**一样的东西**       |
| **so**   | 如此、这样     | 前面的**情况/判断**        |
| **it**   | 它             | 前面提到的具体东西 / 事情  |

示例：

- He is very kind. I've never met **such a person.** -> 这样的人
- I bought a phone. He bought **the same phone.** -> 同样的手机
- Is the phone good?, I think **so.** -> 我认为还不错（好）
- I bought a car. **It** is expensive. -> 车

### 虚主语 it

因为英语句子通常需要一个主语，所以放一个 `it` 在那里，没有具体对象

示例：

- It is col.
- It is raining.
- It is a men or a woman, or something else?

## 5、不定代词

不明确指出“具体是谁 / 什么”的代词。也就是你不知道、没必要说、或者故意不说具体对象是谁。

### 不定代词举例

some、any、all、each、both、either、neither、one、none、many、much、another、a few、 a little、 enough、every

### 复合不定代词

使用 some、any、 no、every、one（body）、thing、where进行复合

| 指   | 复合代词                                       |
| ---- | ---------------------------------------------- |
| 指人 | someone、anyone、no one、everyone（one=body）  |
| 指物 | something、anything、nothing、everything       |
| 指地 | somewhere、anywhere、nowhere、everywhere       |

## 6、疑问代词

用在疑问句中指人、指物的词。

- 指人：who（主格）、whom（宾格）、whose（所有格）
- 指物：what
- 既可以指人又可以指物：which

示例：

- Who called you?
- Whom did you call? -> 宾格-正式
- Who did you call? -> 日常使用没什么问题
- What is this?
- Which food do you want to eat?

## 7、相互代词

each other / one another = 互相、彼此

传统语法曾经区分：

- each other → 两人
- one another → 三人以上

但现代英语通常不严格区分人数。除非准备考试，遇到语法题。

`动词 + each other` 和 `动词 + 介词 + each other`

关键不是 `each other` 要求介词，而是**前面的动词决定需不需要介词。**

这里将 `each other` 替换为 `one another`也是一样的意思，

示例：

- We should learn from each other
- We help **each other**
- We talk to each other
- We work with each other
- We help **one another**
- We work with one another

`each other` 与 `one another` = 意思基本一样。日常使用频率`each other`较高，而且两个人、三个人以上都能用。

## 8、关系代词/连接代词

关系代词 = 连接两个句子，同时代替前面名词的代词。

| 关系代词       | 指代   | 在从句中的作用                 |
| -------------- | ------ | ------------------------------ |
| **who**        | 人     | 主语；宾语（现代英语常用）     |
| **whom**       | 人     | 宾语（正式）                   |
| **whose**      | 人/物  | 所属 （谁的 / 什么东西的）     |
| **which**      | 物     | 主语 / 宾语                    |
| **that**       | 人/物  | 主语 / 宾语                    |

示例：

I know the man. The man is a teacher.

这里的`The man` 重复了两次，我们可以用`who`把它们连接起来：

I konw the man who is a teacher.

这里的 `who` = `the man`，同时把两个句子连接起来，所以叫**关系代词**

---

I bought a phone. The phone is very expensive. = I bought a phone `which` is very expensive.

---

I drive a new car. The new car is cool. = I drive a new car `that` is cool.

---

I konw a girl. Her red laptop is very nice. = I konw a girl `whose` red laptop is very nice.
