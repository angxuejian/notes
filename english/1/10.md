# 动词（Verb）

表示动作或状态的词

动词形态变化通常不会改变动词的核心词义，但会改变它携带的语法信息；有些语法信息会进一步影响整个句子的意思。

## 1、实义动词

表示主语的动作或状态，可以根据`带不带宾语`分成两类

### 1.1、及物动词 Vt

在及物用法中，可以直接带宾语。然后又根据`带不带宾补`分成两类。

#### 1.1.1、完全及物动词

一定要带`宾语`表意才完整，无需`宾补` = S(Subject) + V(Verb) + O(Object) = 主谓宾句型

- I hear music.

- I like you.

#### 1.1.2、不完全及物动词

一定要带`宾语且宾补`表意才完整 = S(Subject) + V(Verb) + O(Object) + C(Complement) = 主谓宾补句型

- I made you happy

- I saw him dance

##### 1.1.2.1、使役类动词

##### 1.1.2.2、知觉类动词

##### 1.1.2.3、任命/认定类动词

##### 1.1.2.4、其他无法归类且重要不完全及物动词

### 1.2、不及物动词 Vi

不带`宾语`也能表达完整意思 = S(Subject) + V(Verb) = 主谓

- He failed

- He left

- I listen

通过`介词`可以带上`宾语` = S(Subject) + V(Verb) + PP(Prepositional Phrase) = 主谓介词短语

- She's aiming

- She's aiming at the target

### 1.3、总结

同一个单词可能有多种用法。Vt / Vi 更适合理解成当前用法的属性，而不是这个单词永远固定的身份。

因为像 eat：

- I eat. → 不及物用法

- I eat an apple. → 及物用法

还有无需过度纠结为什么要分为`及物动词`和`不及物动词`。可以先理解为英语长期使用形成了不同的动词搭配习惯。有些动词可以直接接宾语，有些则需要通过介词连接。学习时更重要的是把常见结构作为 chunk 记忆

举例:

对于及物动词：

- I like you.

属于很标准的主谓宾结构。

但是对于不及物动词`listen`来说：

- I listen

属于主谓结构，要加宾语必须要使用介词：

- I listen to music

但是日常交流假设使用：

- I listen music

虽然不符合标准英语语法，但在上下文明确的日常交流中，对方通常仍然能够推测出想表达的是 `I listen to music`。学习时不必因为担心漏掉介词而不敢开口，但目标仍然是逐渐形成 `listen to + something` 的 `chunk`。

## 2、系动词（Linking verb）

### 2.1、五感

举例：

- It tastes delicious

- The flowers smell good

- The music sounds bad

### 2.2、四变

become、get、grow、turn

举例：

- He became angry

- It's getting cold

## 3、助动词（Auxiliary Verb）

本身无实意，用于协助动词以构成时态、语态、否定、疑问、语气。

do、does、did、will、shall、should、would、could、be、being、been

举例：

- Everything will be OK. （未来时态）

- Did I say that? （疑问）

## 4、情态动词（Modal Verb）

放在实义动词前面，给这个动作增加“能、会、应该、必须、可能、愿意”等态度/可能性。

比如同一个动作 go：

- I go. → 我去。

- I can go. → 我`能`去。

- I may go. → 我`可能`去。

- I should go. → 我`应该`去。

- I must go. → 我`必须`去。

- I will go. → 我`会`去。

真正的动作一直都是 go。变化的是说话人对 go 这个动作的态度、能力、可能性、必要性、意愿等。

### 常见情态动词

| 情态动词 / 表达 | 核心含义                     | 大致中文感觉   | 例句                   |

| --------------- | ---------------------------- | -------------- | ---------------------- |

| **can**         | 能力 / 许可                  | 能、可以       | I **can do** it.       |

| **could**       | 过去能力 / 委婉请求 / 可能性 | 能、可以、可能 | **Could** you help me? |

| **may**         | 许可 / 可能性                | 可以、可能     | It **may rain**.       |

| **might**       | 较弱的可能性                 | 可能、也许     | It **might rain**.     |

| **will**        | 将来 / 意愿                  | 会、将会、愿意 | I **will do** it.      |

| **would**       | 假设 / 委婉 / 过去的意愿     | 会、愿意       | **Would** you help me? |

| **must**        | 强烈义务 / 必要性            | 必须           | You **must go**.       |

## 5、动词的五种基本形式

1. 动词原形（do）

2. 第三人称单数（does）

3. 过去式（did）

4. 现在分词（doing）

5. 过去分词（done）

| 动词形式         | 例句                                  | 中文                     |

| ---------------- | ------------------------------------- | ------------------------ |

| **原形**         | I **work** on this issue every day.   | 我每天处理这个问题。     |

| **第三人称单数** | He **works** on this issue every day. | 他每天处理这个问题。     |

| **过去式**       | I **worked** on this issue yesterday. | 我昨天处理了这个问题。   |

| **现在分词**     | I'm **working** on this issue.        | 我正在处理这个问题。     |

| **过去分词**     | I've **worked** this issue.           | 我已经处理完这个问题了。 |

### 5.1、动词原形（do）

原称：original verb、base form，即动词的原始形式，尚未变化的形式。

动词原形出现的几种情况

1. 不定时标志to的后面

   - Would you like `to dance` with me?

2. 情态动词后面

   - He `can help` you

3. 助动词后面

   - `Did` he `pick` you up?

4. 使役动词后面

   - I will `let` she `know`

5. 感官动词后面

   - I `saw` him `enter` the building

6. 祈使句开头

   - Come in

7. 特殊句式里

   - `Why not` take a break

### 5.2、第三人称单数（does）

第三人称单数（he / she / it / 单数名词 / 不可数名词）做主语，且为一般现在时 = 动词 + s

变化规则

1. 大部分动词直接加 `-s` (works, plays, reads)

2. 以 `s`、`x`、`o`、`ch`、`sh`结尾时加 `-es` (kisses, fixes, washes, watches, does)

3. `辅音字母` + `y`结尾时 把`y`变`i`，然后加 `-es` (fly -> flies, carry -> carries)

4. `元音字母` + `y`结尾时 直接加 `-s` (plays, enjoys)

5. 特殊情况：`have -> has`，`be -> is` (He has a dog)

举例

- He is a dog.

- She plays baseball

- It is cool

如何区分元音和辅音

> 元音字母：a、e、i、o、u； 其余全是辅音字母

所以看到 y 结尾的动词，你甚至不用想「什么叫辅音」，只看 y 前面那个字母是不是 a/e/i/o/u。

举例：

| 动词  | y 前面的字母 | 判断 | 三单    |

| ----- | ------------ | ---- | ------- |

| play  | **a**        | 元音 | plays   |

| enjoy | **o**        | 元音 | enjoys  |

| say   | **a**        | 元音 | says    |

| study | **d**        | 辅音 | studies |

| carry | **r**        | 辅音 | carries |

| fly   | **l**        | 辅音 | flies   |

### 5.3、过去式（did）

表示过去发生的动作或状态时，动词使用过去式。

变化规则

1. 大部分动词直接加 `-ed` (worked, played, wanted)

2. 以`e`结尾时加 `-d` (lived, moved, hoped)

3. `辅音字母` + `y` 结尾时 把`y`变`i`， 然后加 -ed (study -> studied)

4. `元音字母` + `y` 结尾时 直接加 `-ed` (played, enjoyed)

5. `重读闭音节`，且结尾是`一个元音字母` + `一个辅音字母`，通常双写最后的辅音字母，再加 `-ed` (stop -> stopped, plan -> planned)

6. 不规则动词需要单独积累，还有很多很多

    - go → went

    - see → saw

    - eat → ate

    - take → took

    - have → had

    - do → did

举例：

- He `works` here. → `Does` he work here?

- He `worked` here. → `Did` he work here?

`worked` -> `Did` = 一个地方已经承担了这个语法信息，后面的动词通常就不用再重复承担。

### 5.4、现在分词（doing）

主要用在进行时；也可以作定语、状语等。

变化规则

1. 大部分动词直接加 `-ing` (working, playing, wanting)

2. 以`不发音`的`e`结尾时, 移除`e`加`-ing` (living, moving, hoping)

3. 以`y`结尾时 直接加 `-ing` (playing, enjoying)

4. `重读闭音节`，且结尾是`一个元音字母` + `一个辅音字母`，通常双写最后的辅音字母，再加 `-ing` (stop -> stopping, plan -> planning)

5. 以`ie`结尾时，把`ie`变`y`，然后加 `-ing` (lie -> lying, die -> dying)

6. 以`c`结尾时，加`k`，然后加 `-ing` (picnic -> picnicking)

常见搭配：

1. be + doing → 进行时

    - I **am working** -> 主 + 谓（现在进行时）

### 5.5、过去分词（done）

完成时态以及被动语态中使用

变化的基本规则与过去式一样

1. 大部分动词直接加 `-ed` (worked, played, wanted)

2. 以`e`结尾时加 `-d` (lived, moved, hoped)

3. `辅音字母` + `y` 结尾时 把`y`变`i`， 然后加 -ed (study -> studied)

4. `元音字母` + `y` 结尾时 直接加 `-ed` (played, enjoyed)

5. `重读闭音节`，且结尾是`一个元音字母` + `一个辅音字母`，通常双写最后的辅音字母，再加 `-ed` (stop -> stopped, plan -> planned)

6. 不规则动词需要单独积累，可以按 `原形 - 过去式 - 过去分词` 的变化形式辅助记忆：

    - AAA: put-put-put, cut-cut-cut

    - ABB: spend-spent-spent, feel-felt-felt

    - ABC: fall-fell-fallen, speak-spoke-spoken

    - AAB: beat-beat-beaten

    - ABA: run-ran-run, come-came-come, become-became-become

如何区别过去式和过去分词：

- 过去式：自己就能当谓语，表达“过去做了”。

- 过去分词：通常不能自己干，要跟 have 或 be 搭配。

通常遇到这两大家族，都是属于过去分词：

- have 家族 + done → 完成时

- [be 家族](../be.md) + done → 被动语态

have 家族：

- have → 原形/现在时

    - I have done it.

- has → 三单

    - She has done it.

- had → 过去式

    - I had a car.

- having → 现在分词

    - I am having lunch.

- had → 过去分词

    - I had done it.
